- JavaScriptから参照するHTML IDの欠落：なし
- 一覧・物件詳細で生成する一時画像URLを、再描画・詳細画面終了時に解放するよう修正

- バックアップファイル名の日付をUTCではなく端末のローカル日付で生成

- バックアップ出力時の未使用JSONシリアライズを削除し、大きな画像を含む場合の不要なメモリ・処理負荷を削減

## 4. 重要な保存・料金上の注意

- 記録と画像は現在のブラウザ内IndexedDBに保存。端末間自動同期はない。
- ブラウザデータ消去・端末故障に備え、バックアップを定期的に取得する。
- バックアップ復元は現在のデータを置き換える。
- AI解析は未接続。APIキー入力もAPI呼び出しもなく、AI従量課金は発生しない。
- 地域別参考額は2026-11-25調査時点の参考情報。行政の個別認定・支給額・制度利用資格を判定しない。
- 面積別減額は大阪市の確認済み例のみ数値反映。他市の額は推測しない。
- 現行公開版およびルートのファイルは変更していない。Previewと実機確認の合格後にのみ切替を検討する。

## 5. 実装時の安全原則

- AI解析がなくても保存・整理・比較が動作する。
- AI失敗や429で別の有料サービスへ自動フォールバックしない。
- 手入力値をAI再解析で無断上書きしない。
- 未確認を「不適合」と同一視しない。
- AIは契約判断を代行しない。
