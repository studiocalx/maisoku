# マイソクAI 2.0 — 開発プレビュー

このディレクトリは、既存の公開版を維持したまま2.0を検証するための独立した試作です。

## 現在できること
- 物件の登録・編集・一覧・キーワード検索
- 街／訪問記録の登録・編集・一覧
- 物件と訪問記録の関連付け
- カメラ撮影または画像選択による原画像のIndexedDB保存
- 未整理資料の一覧・物件への紐付け・削除
- 物件ごとの複数資料の表示
- JSONバックアップ（画像データを含む）と復元
- アプリ画面のオフラインキャッシュ（初回アクセス後）

## まだ実装していないこと
- Gemini等のAIによるマイソク読み取り
- OCR結果と手入力値の差分確認・情報源管理
- 評価マトリクス、地域比較、物件比較
- 内見・契約チェックリスト
- 画像容量の事前警告・ストレージ管理
- 実機テストとCloudflare Pages Previewでの動作確認

## 保存とプライバシー
- 記録・画像は利用中ブラウザのIndexedDBに保存される。サーバーへの自動送信や端末間同期は行わない。
- ブラウザデータの消去や端末故障に備え、JSONバックアップを定期的に書き出す。
- バックアップの読み込みは現在のデータを置き換える。実行前に現在のデータも保存すること。
- AI解析はまだ接続していないため、APIキー・AI利用料金は発生しない。

## プレビュー
Cloudflare PagesでこのブランチをPreviewデプロイした場合のパスは `/v2/`。
本番URLや既存版のルートは変更しない。実機確認とユーザー承認が済むまで本番切替を行わない。
