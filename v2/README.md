# マイソクAI 2.0（賃貸版）— studioCALX

賃貸物件のマイソク（募集図面）を撮影・AI読み取りし、物件・地域・訪問記録を蓄積して評価・比較するための個人用Webアプリです。ブランド表記は studioCALX、タグラインは「AI × Web × Impact」です。

自分のペースで進める「終の棲家」探しのための道具として、物件の評価と地域の評価を別々に蓄積し、判断の時点で組み合わせられる設計にしています。

## 機能一覧

- **マイソク撮影・AI読み取り**: 原画像を先にブラウザ内（IndexedDB）へ保存してから、圧縮画像を Gemini API へ送信して約40項目を抽出。抽出結果は差分画面で現在の値と並べて確認し、採用した項目だけを反映します。手入力した値をAIが黙って上書きすることはありません（各項目に出典：AI読み取り／手入力／手修正などを保持）。
- **物件の記録と評価**: 家賃・管理費・初期費用・契約条件・設備などを項目別に記録。評価は6カテゴリ（アクセス／生活導線／住戸／費用／建物・管理／要確認事項）の固定ルールでJSが計算し、AIは採点しません。未確認項目は減点せず「情報不足」として扱い、評価充足率と信頼度を併記します。対象外（N/A）と情報不足は区別されます。
- **評価スナップショットと履歴**: 登録・編集・資料追加・手動再評価のたびに評価を履歴として保存（上書きしません）。変更された項目と変更理由も記録され、当時の基準バージョンのまま残ります。
- **手動判定**: 自動判定項目は「対象外」のみ手動変更可。手動判定項目は○△×を付けられます。
- **公開用サマリー／内部詳細**: 対外向けの短評・注目ポイント・確認事項と、内部向けの項目別判定表・リスク・費用注意・契約注意・不動産会社への確認事項（「確認すべき事実」と「相談できる可能性」を分離）を分けて表示します。
- **地域評価**: 20項目の地域評価を物件とは独立に蓄積し、同じ地域の複数物件で再利用します。評価履歴もスナップショットで残ります。
- **訪問記録**: 不動産会社・担当者・会話メモ・紹介物件・印象・次回確認事項・写真を記録。訪問記録を消しても物件は消えません。
- **チェックリスト**: 内見チェック7項目・契約前チェック9項目。各項目に状態・メモ・写真を残せます。
- **物件比較**: 2件以上を選んで、家賃・管理費・初期費用目安・間取り・面積・築年・構造・駅徒歩・スコア・充足率・判定を並べて比較。未確認は「未確認」と表示し、推測で補いません。
- **基本条件と予算**: 月額予算の目安と基本条件6件を設定でき、物件ごとに適合状況を確認できます。重み（×1〜×3）は設定で変更でき、変更すると基準バージョンが上がり次回評価から適用されます。
- **住居費の参考表示**: 対象6市（大阪市・枚方市・門真市・八尾市・東大阪市・尼崎市）については、調査時点の参考額を「参考情報・採点対象外」と明記して表示します。評価の軸ではありません。
- **未整理資料**: 行き先の決まっていない画像をためておき、後から物件・訪問記録へ紐付けできます。
- **オフライン対応**: アプリ本体は Service Worker でキャッシュされ、記録の閲覧・編集はオフラインでも可能です（AI読み取りのみオンライン必須）。

## データ保存とバックアップ

- 物件・地域・訪問記録・画像は、利用中ブラウザの IndexedDB に保存されます。サーバーへの自動同期や端末間同期はありません。
- 端末変更やブラウザデータ消去でデータは失われます。「データ管理」から画像を含む全データのJSONバックアップを定期的に書き出してください。最終バックアップ日時が表示されます。
- バックアップの読み込みは現在のデータを置き換えます。復元前に現状のバックアップも取ることをおすすめします。旧バージョン（v1形式）のバックアップも読み込め、賃貸版の形式へ自動変換されます。参照先が見つからない項目がある場合は警告件数を表示します（復元自体は可能です）。

## AIと料金についての注意（明朗会計）

- AI読み取りを実行すると、圧縮した画像が Cloudflare Pages Functions 経由で Gemini API へ送信されます。原画像はブラウザ内に保持されます。
- GEMINI_API_KEY は Cloudflare 側の環境変数（Secret）としてのみ保持し、ブラウザへは露出させません。
- Gemini API の利用には Google 側の利用枠・料金条件が適用されます。無料枠を超えると利用料が発生しうるため、利用状況は Google AI Studio 側でご確認ください。無料利用を保証するものではありません。
- AIは資料に書かれた事実の抽出と定性分析を担当し、資料にない情報は補完しません。採点はブラウザ側の固定ルールで計算します。
