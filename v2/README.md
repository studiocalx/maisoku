# マイソクAI 2.0 — 開発プレビュー

このディレクトリは、既存の公開版を維持したまま2.0を検証する独立した試作です。

## 現在コードに実装した機能
- 物件の登録・編集・一覧・キーワード検索
- アプリ内でマイソク画像をGemini OCR解析し、読み取り結果を物件登録フォームへ反映（原画像を先にIndexedDBへ保存）
- OCR抽出項目：物件名、賃料、管理費、敷金・礼金、駅・徒歩分数、間取り、面積、築年、構造・階数、所在地、備考
- OCR結果は編集可能な入力欄として表示し、原本確認後にユーザーが保存。読み取り失敗時も原画像は未整理資料に残す
- 街／訪問記録の登録・編集・一覧
- 物件と訪問記録の関連付け
- カメラ撮影または画像選択による原画像のIndexedDB保存
- 未整理資料の一覧・物件への紐付け・削除（スマホ向けの物件選択ダイアログ）
- 物件ごとの複数資料の表示
- JSONバックアップ（画像データを含む）と復元
- 物件2件以上の横並び比較
- 内見・契約チェックリストとメモの保存
- 6市の地域別住居費参考値、大阪市の面積別参考額、自治体参照リンク
- アプリ画面のオフラインキャッシュ（初回アクセス後）
- 一覧・詳細画面で使う一時画像URLの解放（長時間利用時のメモリ増加を抑制）
- 新しいService Workerキャッシュ名による更新反映
- バックアップ復元前のデータ構造・ID・画像データ形式チェック

## まだ実装していないこと
- OCR結果と手入力値の差分確認・情報源管理（現状は原本画像との目視照合）
- OCRの実画像読み取り・Cloudflare Preview上のAPI接続・APIキー設定の実地確認
- 旧Gemini評価マトリクスを使った設定可能な評価エンジン
- 地域比較ビュー
- 画像の端末への個別ダウンロード、容量管理
- 実機テストとCloudflare Pages Previewでの動作確認

## 保存とプライバシー
- 記録・画像は利用中ブラウザのIndexedDBに保存される。サーバーへの自動送信や端末間同期は行わない。
- ブラウザデータの消去や端末故障に備え、JSONバックアップを定期的に書き出す。
- バックアップの読み込みは現在のデータを置き換える。実行前に現在のデータも保存すること。
- OCRはCloudflare Pages Functionsの `/api/analyze` 経由でGemini APIを呼び出す設計。`GEMINI_API_KEY` はCloudflare側のSecretとして設定し、ブラウザへ露出させない。Secretの設定状態と実際の読み取り成功はPreviewで別途確認する。
- Gemini APIの利用にはGoogle側の利用枠・料金条件が適用される。無料利用枠の範囲や継続利用費用はアカウント設定に依存し、無料を保証しない。
- 地域別住居費参考値は調査時点の参考情報で、制度利用資格や個別支給額を判定しない。
