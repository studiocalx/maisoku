# マイソクAI 2.0 — GEM分譲マンション査定 開発プレビュー

既存公開版を維持したまま、分譲マンション資料のOCR・GEM査定を検証する開発版です。

## 現在コードに実装した機能

- 分譲マンション販売資料・物件概要資料の画像をAI OCR
- OCR抽出項目：物件名、所在地、交通、構造、専有面積、販売価格、競売の最低買受価格、管理費、修繕積立金、滞納額、占有状況、築年、階数、管理会社、長期修繕計画、大規模修繕履歴、専有部配管履歴
- OCR前に原画像をIndexedDBへ保存
- OCR結果を分譲マンション査定フォームへ反映し、原本照合・手修正後に保存\n- Geminiによる定性的なGEMレビュー（公の短評・注目ポイント・専門的確認質問・内部所見）
- GEM Ver.2.1の評価指標に基づく固定ルールの採点エンジン
- 100点換算の適合スコア、評価充足率、◎／◯／△／☓の暫定判定
- 公の検討用サマリーと、個別戦略資産監査の表示
- 追加資料を既存物件へ紐付け、既存情報を更新して再評価
- 物件の一覧・検索・比較、現地確認チェックリスト
- 街／訪問記録、画像の未整理資料保存
- JSONバックアップ（画像データを含む）と復元
- オフライン用アプリシェル

## 採点仕様上の重要事項

GEM Ver.2.1の原文には、各項目の数値配点や点数閾値は指定されていません。そのため現在の100点配点は、アプリ実装のために明示した暫定案です。正式な旧GEM配点を再現したものではありません。

- AIは資料に書かれた事実の抽出を担当し、資料にない情報は補完しません。
- 採点はブラウザ側の固定ルールで計算し、同じ入力には同じ点数を返します。Geminiは定性的所見を作成しますが、数値点数を決めません。
- 未確認項目は減点せず、採点対象外とし、評価充足率を併記します。
- 評価充足率が低い場合や主要項目が未確認の場合、総合判定は「判定保留」とします。
- 販売価格の市場妥当性・鑑定評価を行うものではありません。市場流動性は現状、資料と現地確認に基づく手動評価です。
- 地域環境監査（街の20項目と自治体比較）は、まだ実装していません。
- 生活保護関連の地域調査・判定は、ユーザー方針により後回しです。

## 保存とプライバシー

- 物件・訪問記録・画像は利用中ブラウザのIndexedDBに保存されます。サーバーへの自動同期や端末間同期はありません。
- AI OCRを実行する場合、圧縮した画像がCloudflare Pages Function経由でGemini APIへ送信されます。原画像はブラウザ内に保持されます。
- GEMINI_API_KEY はCloudflare側のSecretとして設定し、ブラウザへ露出させない設計です。
- Gemini APIの利用にはGoogle側の利用枠・料金条件が適用されます。無料利用を保証しません。
- バックアップの読み込みは現在のデータを置き換えます。復元前に現状データをバックアップしてください。
